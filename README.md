# CakeAtelierWebPage
A webpage for Delivery of Cake, Pasta and Cupcakes through client admin interface.

## Contents
- HTML/CSS Design of the Webpage are presented in this repository while database structure and PHP code of the Webpage are kept as private.
- Layout of HTML/CSS layouts of the Webpage are presented
- Updates on Backend part including integrated PHP codes with Myql connections are planned to be presented in the future.
